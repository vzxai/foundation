# foundation

| Project | What it is |
|---|---|
| [`cultural-horizons-bluesky/`](cultural-horizons-bluesky/) | Stage 2 of the cultural horizons study. It tests whether community boundaries (Bluesky moderation lists) stop fresh artifacts from crossing, by direct repost or by re-made copies. The pipeline is validated on synthetic data; no real data has been analyzed yet. |
| [`winds-out-of-noise/`](winds-out-of-noise/) | A six-minute corecore film for an installation, built entirely in code: public-domain archival and NASA footage, generative visuals, and a synthesized score that moves through noise, classical, hyperpop and post-hyperpop as stages of emergence. |
